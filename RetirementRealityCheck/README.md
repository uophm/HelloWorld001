RetirementRealityCheck
======================

A .NET 8 command-line application for retirement planning checks.

## Prerequisites

* [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

## Build & Run

To build and run the application from the project directory:

```bash
cd RetirementRealityCheck
dotnet build
dotnet run
```

Alternatively, from the solution root:

```bash
dotnet run --project RetirementRealityCheck/RetirementRealityCheck.csproj
```

## Publish

To publish the application as a Release build:

```bash
dotnet publish -c Release -o publish
```
